Numerical Methodology#

The numerical simulations were carried out by Incompact3d, an open source tool based on a Boussinesq system for incompressible fluids, designed for supercomputers. A forked version of the original code was developed for this work [Schuch, 2020] in order to simulate the plunging flow, and it is included in this repository (see Running the Solver).

The code is based on high-order finite-difference schemes and a predictor-corrector method for the Navier-Stokes equations, which leads to the resolution of a Poisson equation for the pressure. With a spectral approach using three-dimensional (3D) Fast Fourier Transforms (FFTs) and the concept of modified wavenumbers [Lele, 1992] for this equation, the divergence-free condition is ensured up to machine accuracy. In order to prevent spurious pressure oscillations, the pressure mesh is staggered from the other variables by half a mesh. More information regarding the numerical aspects of Incompact3d is available in Laizet and Lamballais [2009].

The computational domain is divided into several pencils, each one solved by a different MPI process, resulting in a highly scalable 2D domain decomposition. A complete description concerning the parallel strategy can be found in Laizet and Li [2011].

The governing equations (1)-(3) are solved under an implicit Large-Eddy Simulation (iLES) approach, in which only the largest and energy-containing flow structures are resolved. The small scales, on the other hand, are not resolved; instead, they are modelled via an artificial dissipation that takes place when computing the viscous term [Grinstein et al., 2007, Sagaut, 2006]. Lamballais et al. [2011] and Dairay et al. [2017] presented a new set of coefficients for the sixth-order compact finite-difference schemes, designed to be over-dissipative at the highest wavenumbers and control the aliasing errors via the viscous term. Notice that the solution only differs from the classic high-order finite-difference scheme at the highest wavenumbers, where even the latter becomes inaccurate.
